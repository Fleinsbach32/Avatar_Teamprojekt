## 5. TP2 — RAG, Modulnummern & Studiengang-Zugriff

Befunde: Modul-IDs liegen als `M-WIWI-…` **und** `T-…` vor (Regex erfasste nur
`M-`); Detailsektionen beginnen konsistent mit `Modul: <Name> [ID]`; das
Zeichen-Chunking zerschnitt Name ↔ ID; der Studiengang-Filter war auf ein PDF
beschränkt; Umlaut-Extraktion ist korrekt (Fehlalarm der Konsole).

Umsetzung:
- `fill_db.py`: **modulweises Chunking** (`chunk_handbook`) — Name + ID bleiben
  pro Chunk zusammen; einheitliche Metadaten
  (`doc_type`/`program`/`module_id`/`module_name`); sauberer Rebuild
  (Collection wird verworfen & neu angelegt); Ausführung in `main()` gekapselt.
- `rag.py`: Regex `M-`/`T-`; Studiengang-Filter via
  `where={"$or": [{"program": key}, {"program": "all"}]}` (Handbuch + FAQ/
  Allgemeines, andere Handbücher aus); exakter `module_id`-Metadaten-Lookup mit
  Volltext-Fallback.
- `prompts.py`: Modulnummern werden **nur auf ausdrückliche Nachfrage** genannt.
- ChromaDB neu aufgebaut: **12.098 Einträge**; Retrieval auf echten Daten
  verifiziert (Modul-ID-Lookup, Studiengang-Filter) — ohne Gemini.
