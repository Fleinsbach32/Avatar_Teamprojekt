## 7. Einheitliches Start-Skript `run.ps1`

Ersetzt `setup.ps1` + `start.ps1` + `start.sh`. Idempotent: `.env` prüfen →
ngrok + pip installieren (nur beim ersten Mal, pip via `.pip-stamp`) → ChromaDB
befüllen (falls fehlt) → ngrok-Tunnel starten und URL ausgeben → uvicorn
(`app.main:app`).

**Bugfix:** Erste Version hatte Box-Zeichen (`─`) und Umlaute in Kommentaren.
Windows PowerShell 5.1 liest UTF-8 ohne BOM im ANSI-Codepage; das Byte `0x94`
aus `─` wurde als `"` interpretiert → offene Zeichenkette → „MissingEndCurlyBrace"
bei Zeile 109. Lösung: `run.ps1` rein ASCII.

## 8. Voice-Pfad: Sprache & Studiengang + 404-Fix

**Problem 1 (Avatar bricht bei Spracheingabe ab):** Log zeigte
`POST /chat/completions 404`. Tavus' OpenAI-Client hängt `/chat/completions` an
die konfigurierte Basis-URL an und traf damit die ngrok-Root. Fix:
`/chat/completions` als zusätzlichen Alias auf `tavus_llm` registriert (neben
`/tavus/llm` und `/tavus/llm/chat/completions`).

**Problem 2 (Voice ignorierte lang/studiengang):** Tavus ruft `/tavus/llm`
serverseitig ohne UI-Felder auf. Lösung: Backend merkt sich `active_voice_prefs`
(global, für lokalen Einzel-Session-Betrieb). Gesetzt bei `POST /tavus/session`,
aktualisiert über den neuen `POST /tavus/settings`. Das Frontend meldet
Sprache/Studiengang via `pushVoicePrefs()` beim Avatar-Start und bei jeder
Änderung während eines laufenden Gesprächs.

Neue Tests: `/tavus/settings` aktualisiert Prefs, `/tavus/llm` nutzt sie,
`/chat/completions`-Alias funktioniert.
