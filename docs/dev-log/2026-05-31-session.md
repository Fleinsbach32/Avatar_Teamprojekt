## 2. Tavus AI Integration

### Architektur

```
Nutzer spricht → Daily.co Mic → Tavus CVI (STT)
    → POST /tavus/llm (OpenAI-Format)
        → ChromaDB RAG + Gemini 2.5 Flash
        → Streaming SSE
    → Tavus Avatar spricht (Daily.co Video)
    → transcription-message Events → Chat-Sidebar
```

### Backend (`main.py`)

Drei neue FastAPI-Endpoints:

| Endpoint | Methode | Funktion |
|----------|---------|----------|
| `/tavus/session` | POST | Erstellt Tavus CVI Konversation via `tavusapi.com/v2/conversations` |
| `/tavus/llm` | POST | OpenAI-kompatibler Streaming-Endpoint — wird von Tavus aufgerufen wenn Nutzer spricht |
| `/tavus/end` | POST | Beendet Konversation via DELETE auf Tavus API |

**Neues Pydantic-Modell:**
```python
class TavusEndRequest(BaseModel):
    conversation_id: str

class TavusLLMRequest(BaseModel):
    messages: list
    stream: bool = True
```

**Neue Imports:**
```python
import json as json_lib
from fastapi.responses import StreamingResponse
```

**`/tavus/llm` Logik:**
1. Letzten `role: "user"` Message aus `messages[]` extrahieren
2. ChromaDB-Query (identisch mit `/chat`)
3. Gemini 2.5 Flash aufrufen
4. Antwort als OpenAI SSE streamen: `data: {"choices":[{"delta":{"content":"..."}}]}`

**`avatar_config` erweitert:** Akzeptiert jetzt auch `AVATAR_PROVIDER=tavus`

### Tests (`tests/test_tavus.py`)

6 neue Tests — alle mit `@patch("main.httpx.AsyncClient")`:

1. `test_tavus_session_success` — Session-Erstellung, prüft API-Key-Header und replica_id

3. `test_tavus_session_api_error` — 401 wenn Tavus API Fehler zurückgibt

5. `test_tavus_end_success` — Session beendet, prüft conversation_id in DELETE-URL
6. `test_tavus_llm_success` — Streaming-Response mit `text/event-stream` und `[DONE]`

**Gesamt: 22/22 Tests grün** (16 alt + 6 neu)

### Frontend (`static/index.html`)

**Neue CDN-Abhängigkeit:**
```html
<script src="https://unpkg.com/@daily-co/daily-js"></script>
```

**Neue globale Variablen:**
```javascript
let tavusCall = null;
let tavusConversationId = null;
```

**`_startAvatarTavus()` Funktion:**
- Erstellt Tavus Session via `POST /tavus/session`
- Erstellt Daily.co Call-Object: `Daily.createCallObject()`
- Joined Daily.co Room mit der `conversation_url`
- `track-started` Event: Video/Audio-Tracks in `avatarVideo`/`avatarAudio` einbinden
- `transcription-message` Event: Gesprochenes in Chat-Sidebar anzeigen (User + Bot)
- `left-meeting` Event: UI zurücksetzen

**`avatarSpeak()` für Tavus deaktiviert:**
```javascript
if (avatarProvider === "tavus") return; // Tavus spricht automatisch über CVI
```

**`beforeunload` Cleanup:**
- `navigator.sendBeacon("/tavus/end", ...)` — Session sauber beenden
- `tavusCall.destroy()` — Daily.co Ressourcen freigeben

## 3. Umgebung & Tooling

### ngrok

Für lokale Entwicklung mit Tavus wird ngrok benötigt (Tavus muss `/tavus/llm` von extern erreichen).

- ngrok 3.39.5 heruntergeladen nach `C:\Users\lucat\ngrok\`
- Dauerhaft zum User-PATH hinzugefügt
- Auth-Token konfiguriert

**Verwendung:**
```powershell
ngrok http 8000
# → BASE_URL = angezeigte https://xxxx.ngrok-free.app URL
```

### `setup.ps1`

Neues Setup-Skript das automatisch:
1. ngrok herunterlädt falls nicht vorhanden
2. ngrok zum PATH hinzufügt
3. Nach Auth-Token fragt
4. Python-Abhängigkeiten installiert (`pip install -r requirements.txt`)

## 4. Neue Environment Variables

```env
TAVUS_API_KEY=...          # Tavus Dashboard
TAVUS_REPLICA_ID=...       # Welcher Avatar-Replica
TAVUS_PERSONA_ID=          # Optional, leer lassen wenn kein Persona
BASE_URL=https://xxxx.ngrok-free.app   # Öffentliche URL für Tavus-Callback
AVATAR_PROVIDER=tavus      # Aktiviert Tavus-Provider
```

> **Wichtig:** `BASE_URL` muss öffentlich erreichbar sein. Bei Free-Plan ändert sich die ngrok-URL bei jedem Neustart → `.env` und Backend neu starten.
